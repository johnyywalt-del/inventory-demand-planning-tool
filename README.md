# Inventory & Demand Planning Tool

Narzędzie Excel łączące prognozowanie popytu (moving average, 
exponential smoothing) z polityką zapasów (EOQ, ROP, safety stock).

## Metodologia
- Prognozowanie: średnia ruchoma i wygładzanie wykładnicze, 
  porównane przez błąd MAD
- Zarządzanie zapasami: model EOQ, punkt zamawiania z buforem 
  bezpieczeństwa

## Jak używać
1. Wpisz dane historyczne sprzedaży w zakładce "3"
2. Prognoza i polityka zapasów przeliczą się automatycznie
